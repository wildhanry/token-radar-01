Peer Radar

Pre-token protocols, valued against the peers that already trade.

How a value is made

A launch is worth what the market already pays for comparable live protocols. For each category this radar takes the median market-cap / TVL ratio of that category's live-token protocols in the same snapshot, blends it with the global median, then adjusts each pre-token protocol's TVL by its 7-day growth, its age (days since DefiLlama began tracking it, spent with no token recorded) and its chain breadth. Implied value = TVL × blended multiple × growth factor × maturity factor × breadth factor. Every factor is printed on every row — disagree with one and you can recompute the board by hand. A protocol here records no token in the snapshot; that is DefiLlama's record, not proof none exists. Implied values are this model's own claim, not a prediction that a token will be issued.

The yardstick: live peers

These protocols already trade. Their market-cap / TVL ratios are the evidence the pre-token values above are built from — the model invents nothing.
